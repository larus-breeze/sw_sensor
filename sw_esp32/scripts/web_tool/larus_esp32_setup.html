Larus ESP32 Setup

Initial flash of the ESP32 over USB, and a printable label with QR code + credentials of the sensor's access point. SSID and password are taken verbatim from the firmware's boot output.

1 · Flash firmware (new board without firmware)

Stored WiFi settings and the AP identity (NVS) are preserved. If the connection fails: hold the BOOT button, briefly press Reset, release BOOT and try again. If a high baud rate fails, choose 115200.
